# ADR-0024：勾选逐行排队、加载失败可重试、页签状态保留

> 状态：生效中
> 摘要：勾选按行排队只锁被勾那行，加/删/拖序等队列清空；进屏加载失败给「重试」；四页签的选中日、展开与草稿跨切换保留
> 日期：2026-11-27 ｜ 关联：[ADR-0014](0014-todo-tasks-with-priority.md)、[ADR-0019](0019-refresh-only-on-reports.md)、[ADR-0021](0021-calendar-dated-tasks.md)、[design/android-client.md](../design/android-client.md)

## 决策

待办与日历的勾选不再共用整屏 `busy`，改成 `togglingIds` 逐行队列：同一行在飞时再点忽略，别的行可以立刻勾；每行失败只回滚自己的 `done` 字段，再以服务端为准重拉，不拖累已经成功或正在飞的行。新建、删除、拖序这类改结构的写操作仍等队列清空才可用。进屏加载失败不再只显示空列表：行内 `Notice` 写清错误原文并给「重试」，点一次重拉，成功后提示自动消失——不恢复常驻刷新图标，ADR-0019 不变。主屏四个页签用 `rememberSaveableStateHolder` 各自保存界面状态：切走再回来，日历选中的日子、未完成/已完成区的展开、录入草稿与滚动位置都还在；从编辑页、更新页返回同样不丢。进程重启后是否恢复取决于系统保留的实例状态，不作承诺。

## 背景

此前待办的所有写操作（勾选、新建、删除、拖序）共用一枚 `busy`：勾一条时整屏动作都禁用，快速连点别的行会被吞掉，手感像"点坏了"。加载失败时界面只剩空列表和"还没有待办"，没有重试入口（ADR-0019 又已经删掉常驻刷新图标），用户只能切页签碰运气。页签切换会重建组合：日历刚选中的日子回到今天、展开的列表收起、录入框清空——在日历加完一条切到待办勾掉，再切回来上下文全丢。

## 备选方案

| 方案 | 主要代价 | 结论 |
| --- | --- | --- |
| 逐行队列 + 结构写等待（本决策） | 两套锁并存，读代码要先分清"改状态"与"改结构" | **采纳**：勾选彼此独立，少量多行状态换来点击不被吞；结构写依赖顺序，等队列清空是正确的保守 |
| 保留整屏 `busy` | 零改动 | 否决：吞点击正是本次要修的交互问题 |
| 不锁，每次点击都发 | 实现最简单 | 否决：同一行连点会让 `done` 的 true/false 请求互相追尾，最终态取决于返回顺序 |
| 整屏锁但行内转圈 | 有反馈 | 否决：仍禁用别的行，反馈不能弥补操作被忽略 |
| 失败自动重试 | 用户少点一次 | 否决：服务端有限速，自动重试会放大 429；让错误可见并手动重试 |
| 恢复常驻刷新图标 | 入口显眼 | 否决：ADR-0019 刚把三屏图标收成一枚；加载失败是偶发态，用一次性的「重试」即可 |
| ViewModel 承载页签状态 | 生命周期更完整 | 否决：当前没有 ViewModel 层，`rememberSaveable` 已能覆盖切页签与页面替换；为四屏状态引架构层不值 |
| 本地缓存列表 | 切回立即有内容 | 否决：ADR-0001 定服务端为唯一真相，缓存会制造第二份数据 |

## 影响

- **得到**：快速勾选不再丢操作；失败影响面缩到一行；加载错误可当场恢复；切页签上下文保留。
- **付出**：`togglingIds` 与 `busy` 并存，新增写操作时必须判断它属于"改状态"还是"改结构"；页签状态留在内存里，进程重启后是否恢复取决于系统实例状态；日历仍是每次进屏拉全量，无缓存（ADR-0021 的代价不变）。
- **返工点**：将来若做分页或离线队列，逐行队列要重写成带重放的写队列；页签状态若要跨进程保留，需落 DataStore。
- **连带决定**：日历表头补「N 条 · 已完成 M」，勾掉一条不用翻列表也能看出完成数；已完成区改成可收起（"已完成 N" + 展开/收起），收起时取消该区正在进行的编辑；加载失败的 `Notice` 与限速、写失败共用同一套样式。

## 复查条件

出现以下情况时重新评估本决策：

- 待办上百条、逐行 PATCH 出现明显排队或触发限速
- 需求方要求离线勾选/离线加条（那时触发 ADR-0001 的复查）
- 页签状态在进程重启后丢失被当成缺陷反馈

## 替代成本参考

Things 的多选勾选、Gmail 的滑动归档都按行乐观更新，失败只回滚那一行；移动端列表把选中项、展开态随导航保留是惯例（Compose 用 `rememberSaveableStateHolder`，iOS 用导航栈），不这么做才会被当成 bug。
