# ADR-0018：启动图标用墨底、纸色 M 与一枚朱印

> 状态：生效中
> 摘要：启动图标是一张自适应图标——墨底 `#1B1C18` 上画纸色描边 M，最后一笔收进一枚转了 -3° 的朱色方印；只有 anydpi-v26 那份矢量加单色层，不铺各密度位图
> 日期：2026-11-27 ｜ 关联：[ADR-0013](0013-editorial-desk-visual.md)、[ADR-0017](0017-drawn-line-icons.md)、[design/android-client.md](../design/android-client.md)

## 决策

`android:icon` 指向一张自适应图标（`mipmap-anydpi-v26/ic_launcher.xml`）：背景层是墨色 `#1B1C18`（`res/values/colors.xml` 里的 `ic_launcher_background`），前景层是一枚纸色 `#F3F3ED` 的描边 M——`strokeWidth 7.5`、`strokeLineCap="square"`、`strokeLineJoin="miter"`，跟界面里的输入线和发丝线同一种笔画；M 的最后一笔落在一个 14×14 的朱色方框里，方框绕落点转 -3°，就是 `StatusStamp` 那枚印章的语言。另配一张同几何形状的单色层（`ic_launcher_monochrome.xml`，全白），供 Android 13+ 的主题图标取形。整图标只此一份矢量，不铺 `mipmap-*dpi` 位图。

## 背景

需求方 2026-11-27 要求给 App 设计一个符合主题的图标，此前 `AndroidManifest.xml` 里根本没有 `android:icon`，桌面用的是系统默认机器人。约束是 ADR-0013 那套「编辑部案头」：纸墨色板、方角、只有朱红一种强调、线代替盒子。图标是这套语言里唯一会被拿到 App 外面看的东西——桌面壁纸、最近任务卡、系统应用列表三处，尺寸从 108dp 一路缩到 48dp 以下，还要被各家启动器按圆、方、水滴各种罩子裁一遍。

## 备选方案

| 方案 | 主要代价 | 结论 |
| --- | --- | --- |
| 墨底 + 纸色描边 M + 朱印收笔 | 朱印在 48dp 以下只剩几个像素，靠 M 本身认 | **采纳**：深底在浅色和深色壁纸上都站得住，M 是字母所以不靠"看懂图形"，印章把 ADR-0013 唯一的记忆点带出 App |
| 纸底 + 墨色 M + 朱印 | 同一套形状换个底色 | 否决：纸色 `#F3F3ED` 在桌面浅色壁纸和白色应用列表里跟背景糊成一片，图标边界要靠启动器自己补的阴影才分得出来；墨底不依赖这层运气 |
| 三行手稿压一枚印 | 抽象成"列表"形状 | 否决：三条发丝线缩到 48dp 以下并成一块灰，而且和系统"文档/待办"类图标撞脸——界面里的线之所以是线，是因为旁边有文字，图标上没有 |
| 各密度位图（`mipmap-xxhdpi` 那套 PNG） | 五份要手工对齐的资产 | 否决：minSdk 26（ADR-0015 之后四个变体统一签名，最低仍是 26）起自适应图标全平台支持，位图只是多出来的维护面；而且位图没有单色层，主题图标模式下会被系统自动抠一个更难看的形 |
| 用 ImageGen 生成一张插画再裁成图标 | 一次出图，改不动 | 否决：插画质感和这套方角发丝线是两种东西，而且位图改一笔粗细都要重新出图——ADR-0013 已经为同一类理由否掉过 Material 默认元件的外观 |
| 保持系统默认图标 | 零改动 | 否决：需求方明确要换 |

## 影响

- **得到**：桌面、最近任务、系统应用列表三处同一张形；主题图标模式下由我们自己给单色层，不让系统猜；改一笔只要改 XML，尺寸无关。
- **付出**：墨色在 `colors.xml` 和 `Theme.kt` 各写了一遍——资源层拿不到 Kotlin 常量，这条重复是有意的，两处注释都指向同一个值。
- **返工点**：`res/drawable/ic_launcher_foreground.xml`、`ic_launcher_monochrome.xml`、`res/mipmap-anydpi-v26/ic_launcher.xml`、`colors.xml` 那一行、`AndroidManifest.xml` 的 `android:icon`。换方向是改这几份文件，以分钟计。
- **连带决定**：design §视觉 补一条图标；未决问题「图标与应用名」拆开——图标这条已定，只剩应用名。

## 复查条件

出现以下情况时重新评估本决策：

- 需求方真机桌面上看满一周仍觉得这张图标不对——那是形状本身的问题，不是配色微调能解决的
- ADR-0013 的视觉方向整体返工：图标跟着一起返，不单独保留
- 将来要上应用商店或厂商预装：那时要补一张导出的 512px 位图（自装 APK 这条路不需要）

## 替代成本参考

同类个人记录工具（Dayone、Things、系统自带备忘录）的图标都是「一个字母或一件器物 + 纯色底」，没有用插画的；本决策取的是同一分工——形状只留一个 M 加一枚印，其余交给底色。
