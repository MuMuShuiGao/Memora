# ADR-0017：短动词改用自绘线条图标

> 状态：生效中
> 摘要：待办的加/删、三屏的刷新、编辑页的删除改用自绘线条字形放进 40dp 方框，名称走 contentDescription；连点两次的第二次靠盖一枚朱色方框表达
> 日期：2026-11-27 ｜ 关联：[design/android-client.md](../design/android-client.md)、ADR-0010、ADR-0013

## 决策

界面上「加 / 刷新 / 删」这三个短动词不再写成文字，改成 `Components.kt` 里自绘的线条字形：加＝十字，刷新＝留 60° 缺口、弧头压一枚实心三角的圆弧，删＝描边的垃圾桶（盖、提手、上宽下窄的桶身、两道竖纹）。三者统一装在 40dp 方形点击区里，字形 20dp、笔画约 1.8dp，静止态用墨色（删除用次级墨），禁用态是次级墨降到 45% 不透明度。名称只出现在 `contentDescription` 里，屏幕上不再出现这几个字。删除仍要连点两次（design §交互），第一次不给文字变化，而是给垃圾桶盖一枚 1.5dp 朱色方框、字形同步转朱。

## 背景

需求方 2026-11-27 要求把这三个按钮换成对应图标。约束有三条：ADR-0013 定下的视觉语言（发丝线、方角、只有朱红一种强调、不用 Material 默认元件的外观）；ADR-0010 的最小依赖边界（不新增依赖）；design §文案 的「按钮动词与结果同名」与 §交互 的「删除连点两次」不能因为换成图标就丢掉。原来的文字按钮还有个副作用：`删` 变成 `确认删` 时整行内容会左右跳一次。

## 备选方案

| 方案 | 主要代价 | 结论 |
| --- | --- | --- |
| 自绘线条字形（Canvas 描边） | 三个字形约 80 行绘制代码，形状与视觉重量要自己在真机上一眼一眼校 | **采纳**：笔画跟输入线、勾选框、拖拽把手是同一套东西，不新增依赖，形状完全归本项目管 |
| 直接用 material-icons（`Icons.Default.Add/Refresh/Delete`） | 零绘制代码，随 material3 的传递依赖就在 classpath 上 | 否决：那套是实心字形，跟这片 1dp 发丝线版面是两种笔画——ADR-0013 已为同一条理由否掉 Material 的 Checkbox 和胶囊进度条；而且图标形状从此绑在 Material 的语义上，换视觉方向时要连它一起返工 |
| 图标 + 文字并排 | 横向宽度一点没省 | 否决：换图标的主要收益就是把宽度还给正文，文字再留一遍等于没换 |
| 保留文字，只把名称补进无障碍 | 零改动 | 否决：需求方要的就是视觉上这一眼；三个两字按钮在三种不同屏上重复出现，看着像占位符 |
| 用下拉刷新替掉刷新图标 | 显式入口消失 | 否决：material3 的 PullToRefresh 仍是实验 API（design §交互 已记这条），而「没有推送，点一下才看见另一台设备记的那条」这件事需要有个看得见的手柄 |

## 影响

- **得到**：录入行与页签行省出宽度；三屏的刷新入口形状一致，不用各自对齐文字宽度；删除的第二次确认从「文字变长把整行挤歪」变成一次原地盖印。
- **付出**：认不出图标的人没有文字可读——名称仍在 `contentDescription` 里，TalkBack 读得到；以后改字形要懂一点 Canvas。
- **返工点**：只有 `Components.kt` 的 `IconAction` 与三个 `*Glyph`。Screen 侧调用只传 `icon / label / armed`，想换回文字就是把调用改回 `TextAction`，以小时计。
- **连带决定**：design §交互 里「删除连点两次」的表述改成图标态；`DeskIcon` 只放这三个已经校准过的字形，别把「搜索」「更多」这类还没设计的形状塞进去当 Material 图标用。

## 复查条件

出现以下情况时重新评估本决策：

- 需求方在真机用满一周仍找不到刷新或删除——图标语义不被认出来，届时在同一位置补一句文字，而不是整体换回文字按钮
- 需要第四、第五个字形，且自绘成本明显高过取 material-icons——那时该重新评估的是整套图标语言，不是单个字形
- ADR-0013 的视觉方向整体返工（`Theme.kt` + `Components.kt`），字形跟着换

## 替代成本参考

同类个人记录工具（Things、Bear、系统自带备忘录）的通行分工是：行内动作放单色线条图标，主操作保留文字。本决策与此一致——`记一条`、`存`、`下载` 这些主动作仍是朱红实心块加文字，只有行内的短动词变成图标。
