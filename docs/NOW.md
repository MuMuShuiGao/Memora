## 断点说明

没有"改到一半没验证"的代码。已知粗糙：auth 与 config 没有自己的单测（靠 api 单测和冒烟间接兜住）；待办拖拽只以 `input swipe` 在模拟器验过，真手指的抖动没测；日历每次进屏拉全量、无缓存；跨时区旅行时手机本地日期与服务端缺省日期可能差一天（ADR-0021 的取舍）；日期选择器是 Material 组件，与案头视觉只靠颜色对齐（ADR-0023 的付出）。
**验证口径**：云机内部连自己的公网地址不通（hairpin 不成），防火墙只能由手机或 Windows 侧验；bcrypt 哈希过 systemd `EnvironmentFile=` 不变形；出网实测 `api.deepseek.com` 可达（无 key 回 401）。
**备份链路已通、恢复没演练**：云机首份快照已产出、本机手动拉取哈希一致；恢复步骤没实跑过（下一步 1）；盘外副本改手动（ADR-0026），忘拉就落后，本机副本停在 11-27 那份。
**云机二进制 = 本地构建的 v0.8**：与随后提交的源码同源（先构建后提交，二进制未在云上重编）；v0.7 二进制留在 `/usr/local/bin/memora.bak-20261127-161551`。
**本机联调回路整条留在盘上**：本机 `memora.exe` 听着本地端口，`devlocal/`、`tls-test/` 都在；**当前工作树里 `android/app/src/local/res/raw/memora_server_cert.pem` 是联调证书（已改动、未提交），提交前先 `git checkout --` 还原成云上那张**；`devlocal/` 不提交。devlocal 库里留着交周报/买牛奶两条测试待办（都带心得），会进本机报表素材。
