## 断点说明

没有“改到一半没验证”的代码；关于页已验完，只差提交与发版。已知粗糙：auth 与 config 没有自己的单测；待办拖拽只以 `input swipe` 在模拟器验过；日历每次进屏拉当天任务加 42 天日报区间，没有缓存；跨时区旅行时手机本地日期与服务端缺省日期可能差一天（ADR-0021 的取舍）；日报的“当天完成”按手机本地日筛，不是报表归属口径；日历日均请求失败时墨点不画、只给提示。
**验证口径**：云机内部连自己的公网地址不通（hairpin 不成），防火墙只能由手机或 Windows 侧验；出网实测 `api.deepseek.com` 可达（无 key 回 401）。
**备份链路已通、恢复没演练**：云机快照已产出、本机手动拉取哈希一致；盘外副本手动拉取（ADR-0026）。
**云机二进制 = 上轮的 v0.11**：回滚用 `/usr/local/bin/memora.bak-20261128-115218`；v0.13 部署时按同样方式留旧版。
**本机联调回路留在盘上**：`devlocal/memora-dev.exe`、`devlocal/rel/` 与 `devlocal/memora-linux` 都在；dev 端口 8443、口令哈希仅在 devlocal（不入库）；临时发布清单已删。
