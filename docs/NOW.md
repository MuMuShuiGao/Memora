## 在做什么

- **日报（ADR-0031）**：`dailies` 一天一行、`entry_day` 唯一、三段纯文本（优先级 / 今天做成了什么 / 卡点与没做完的）；`PUT /v1/dailies/{day}` 整份替换，三段全空即无素材，没有删除接口。
- **日报是报表第四种素材**：`source_count` = 记录 + 已完成待办 + 已完成阶段 + 日报天数，四路全空才算空周期；补跑候选也并上日报日。提示词把日报标成本人亲笔，优先级只许进“下一步”，卡点进风险段，与别的素材去重。
- **ADR-0032 已实现并验收（2026-11-28 13:15）**：日报改停顿 1.5 秒自动保存（`Mutex` 串行、翻页/跳转前补存、失败保留可重试、全清显示「这天的素材已清掉」），不再有保存按钮与未保存拦截；文案换成写给自己的话；日历 3dp 墨点 + 选中日「日报」行 + 落在当天的跳转，未来日不显示日报入口；服务端新增 `GET /v1/dailies?from=&to=`（`{days, today, count}`，最多 366 天）与 `PUT` 未来日 400；字阶只动日报与日历两屏。
- **v0.12 已构建未部署**：versionCode 12、release APK 7,708,652 字节；云机二进制与更新目录仍是 v0.11。
- **远端是需求方的公开 GitHub 仓库**，凭据是仓库专用 deploy key（私钥只在 `~/.ssh`，600）；不强推、不改写历史。

## 断点说明

没有“改到一半没验证”的代码。已知粗糙：auth 与 config 没有自己的单测；待办拖拽只以 `input swipe` 在模拟器验过；日历每次进屏拉当天任务加 42 天日报区间，没有缓存；跨时区旅行时手机本地日期与服务端缺省日期可能差一天（ADR-0021 的取舍）；日报的“当天完成”按手机本地日筛，不是报表归属口径；日历日均请求失败时墨点不画、只给提示。
**验证口径**：云机内部连自己的公网地址不通（hairpin 不成），防火墙只能由手机或 Windows 侧验；出网实测 `api.deepseek.com` 可达（无 key 回 401）。
**备份链路已通、恢复没演练**：云机快照已产出、本机手动拉取哈希一致；盘外副本手动拉取（ADR-0026）。
**云机二进制 = 上轮的 v0.11**：回滚用 `/usr/local/bin/memora.bak-20261128-115218`；v0.12 部署时按同样方式留旧版。
**本机联调回路留在盘上**：`devlocal/memora-dev.exe`、`devlocal/rel/` 与 `devlocal/memora-linux` 都在；dev 端口 8443、口令哈希仅在 devlocal（不入库）；本轮验收清空了 dev 库里 11-28 的日报（仅 devlocal）。
