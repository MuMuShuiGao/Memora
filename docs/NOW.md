## 断点说明

没有"改到一半没验证"的代码。已知粗糙：auth 与 config 没有自己的单测（靠 api 单测和冒烟间接兜住）；待办拖拽只以 `input swipe` 在模拟器验过，真手指的抖动没测；日历每次进屏拉全量、无缓存；跨时区旅行时手机本地日期与服务端缺省日期可能差一天（ADR-0021 的取舍）；日期选择器是 Material 组件，与案头视觉只靠颜色对齐（ADR-0023 的付出）。
**验证口径**：云机内部连自己的公网地址不通（hairpin 不成），防火墙只能由手机或 Windows 侧验；bcrypt 哈希过 systemd `EnvironmentFile=` 不变形；出网实测 `api.deepseek.com` 可达（无 key 回 401）。
**本机联调回路整条留在盘上**：本机 `memora.exe` 听着本地端口，`devlocal/`、`tls-test/` 都在；模拟器上的 `com.memora.app.local` 编译前临时拷过 `tls-test/server.crt`，仓库那张已还原，**下次重装要先再拷一次（别提交）**；`devlocal/` 不提交。
**更新链只在真点下才露过的错**（已修）：`canRequestPackageInstalls()` 少个 s；"我开好了，继续安装"不认 `NeedsPermission`；`Installed` 档主屏没有入口；v0.5 首次真机下载被 HTTP/2 单流写超时掐断（ADR-0022 已修）。v0.3–v0.6 是真实涨号发过的版。
