## 在做什么

- **手写日报已实现并发布 v0.11（2026-11-28 11:52）**：ADR-0031 的 `dailies` 一天一行、`entry_day` 唯一、三段纯文本（优先级 / 今天做成了什么 / 卡点与没做完的）；`PUT /v1/dailies/{day}` 整份替换，三段全空即无素材，没有删除接口；只补记不写未来。
