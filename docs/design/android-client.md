# 安卓客户端设计

> 状态：生效中
> 摘要：手机端界面划分、本地只存哪四样、九个接口怎么调、每种错误显示成什么、地址与证书怎么随构建环境切换
> 依据：[ADR-0001](../decisions/0001-server-owned-data-on-lan.md)、[0002](../decisions/0002-single-user-passphrase.md)、[0004](../decisions/0004-manual-and-scheduled-report.md)、[0005](../decisions/0005-no-redaction-in-app.md)、[0008](../decisions/0008-native-kotlin-client.md)、[0009](../decisions/0009-public-ip-selfsigned-https-access.md)、[0010](../decisions/0010-minimal-android-deps.md)；接口契约见 [memo-and-report.md](memo-and-report.md)
> 更新：2026-11-26（与 `android/` 里的第一版代码对齐；构建步骤见仓库 `android/README.md`）

## 目标与非目标

- 目标：掏出来两次点击内进键盘；所有业务数据只在服务端；把 ADR-0009 那条唯一防线在客户端落实——锁定证书、不留忽略开关、口令密文存放。
- 非目标：不做离线读写（ADR-0001，断网只能继续编辑草稿）；不做通知、小组件、多端、附件；**不算归属周期**（算法只在服务端 `internal/period` 一处）；不做脱敏（ADR-0005）。

## 结构

```
四个 Screen（Compose）
      │  只负责显示与输入，不放业务规则
      ├── MemoApi（OkHttp + kotlinx.serialization）── HTTPS ── 服务端 /v1
      ├── CredentialStore（KeyStore 加解密 → 密文进偏好文件）
      └── LocalStore（DataStore：地址、草稿、上次选的周期）
```

| 模块 | 职责 | 依赖谁 |
| --- | --- | --- |
| `AppRoot` 状态机 + 四个 Screen | 显示、输入、把 `ApiError` 翻成文案 | MemoApi、LocalStore |
| `MemoApi` | 九个挂起函数，请求拼装与错误解析只在这一处 | OkHttp、kotlinx.serialization |
| `ApiError` | 把 HTTP 状态码 + `error.code` 收成界面能分支的十二种情况，`describe()` 给文案 | — |
| `CredentialStore` | 口令的存取，明文只存在于内存 | 系统 KeyStore |
| `LocalStore` | 地址、草稿、报表页上次选的 kind | DataStore |
| Gradle flavor | 默认地址 + 该环境的证书 | 见 §6 |

页面切换用状态机（`AppRoot` 决定显示哪一屏，编辑页是把主屏整块换掉），不引导航库：这个 App 只有"连接 → 主屏 → 编辑"一条纵深，导航库带来的返回栈、路由参数、目的地序列化都得多写一层，换来的能力用不上。

## 数据

客户端上一共只有四样东西，全都不是业务数据：

| 存什么 | 放哪 | 为什么 | 生命周期 |
| --- | --- | --- | --- |
| 访问口令 | KeyStore 的 AES/GCM 加密后存偏好文件（IV 与密文一起，Base64） | ADR-0008 连带决定：明文落偏好文件等于把 ADR-0002 那唯一防线交出去 | 装到卸载；连接页有"清除口令" |
| 服务器地址 | DataStore 明文 | 地址不是秘密，且换 IP / 换网要能改；值本来就在手机里 | 同上 |
| 未提交的录入正文 | DataStore | 需求 §5 第 3 条：进程被杀不能让用户白打一段字（服务端不管这个） | 保存成功或用户清空后删除 |
| 报表页上次选的周期与 kind | DataStore | 只省点击 | 随时可丢 |

**不存记录列表，也不存报表正文缓存**。ADR-0001 定的是服务器为唯一权威副本，而 FR-01 的验收线恰好是"两台设备看到同一条"——手机上留一份缓存，就等于制造第二个真相，而且是最难复现的那种不一致。

## 界面

ADR-0008 说界面三块（列表、录入、报表）。这里有四屏：口令与地址必须有输入入口，那是 ADR-0002 和 0009 的直接后果，不是新增需求。

| 屏 | 内容 | 什么时候出现 |
| --- | --- | --- |
| 连接 | 地址、口令、"测试并保存"（拿一次 `periods/now` 当验收）、"只保存，先不测" | 没配过时；之后只在 401 时回来 |
| 记录 | 最新在前、关键词过滤（`q`）、刷新按钮、点条目进编辑、"记一条"按钮 | 主屏第一个 tab |
| 编辑 | 多行输入、`n/上限` 计数、保存；已有条目带删除（连点两次才删） | 新建与修改共用一屏，整块替换主屏 |
| 报表 | 周/月切换、周期列表（含 `status`）、单份正文、生成按钮、复制到剪贴板 | 第二个 tab |

顶栏第三个入口是"改口令 / 改地址"：清掉 KeyStore 里的口令与别名，回到连接页。401 走的是同一条路。

三条交互定论，不是建议：

1. **生成按钮点了就转圈到接口返回**。服务端是同步生成（ADR-0004），一次可能要 60s 预算加一次重试；客户端造一个假进度或轮询状态，只会把"服务端正在等模型"这件事藏起来。
2. **进行中的本周/本月也能点生成**（FR-06），界面显示服务端给的 `source_count` 与 `generated_at`，不自己算"截至哪天"。
3. **failed 必须把 `fail_reason` 显示出来**（FR-05 不静默缺失）。`pending`/`running` 在单份响应里出现时显示"进行中"，不许显示成空白正文。

## 接口调用与错误显示

请求形状、字段、状态码以 [memo-and-report.md §5](memo-and-report.md) 为准，这里只定客户端拿到每种错误时干什么：

| 情况 | 界面动作 |
| --- | --- |
| `401 unauthorized` | 提示"口令不对"，跳连接页，丢掉内存里的口令。不自动重试——重试只会喂限速计数 |
| `429 rate_limited` | 提示"试太快，N 秒后再试"，N 取 `Retry-After`，期间按钮禁用 |
| `400 bad_request` | 直接显示服务端 `message`（本来就写成人话，如"before 要 RFC3339"） |
| `404 not_found` | "这条已经不在了"，从列表移除该条 |
| `404 not_generated` | 空态 + 生成按钮，不算错误 |
| `409 no_records` | "这个周期一条记录都没有"，显示成空态而不是错误 |
| `413 too_large` | 正常路径不该出现（客户端先挡），真收到就把服务端原文显示出来 |
| `502 generation_failed` | 显示响应里那条 `report.fail_reason` |
| `503 llm_not_configured` | "服务端没配模型"——这句话要区别于"模型出错"，否则用户会去查自己网不好 |
| `5xx` / `internal` | "服务端出错了"，附 `code` |
| `IOException`（连不上、超时） | "连不上服务器"，附当前地址；这是唯一该提示检查网络的分支 |
| `SSLHandshakeException` / `SSLPeerUnverifiedException` | "证书与地址不匹配，或打进来的证书不是这个环境的"——见 §6，这条几乎总是 flavor 与证书配错了 |

超时：连接 15s，读取 90s。读取必须**大于**服务端单次生成的 60s 预算加一次重试余量，否则客户端先断开、用户看到"连不上"，而报表其实正在库里落地——那是最容易被误判成产品坏了的组合。

## 结构细节：周期从哪来

报表接口要 `period_start`，客户端手上没有这个值，而"算周一"这件事**不许在 Kotlin 里再写一遍**：那条规则一旦有两份实现，改口径就要改两处，而客户端那份没有任何测试能发现它跟服务端不一致，`make smoke` 也测不到它。

所以 `GET /v1/periods/now`（见 memo-and-report §5）返回当前周与月的起止日，报表页启动时取一次，"生成本周"直接拿 `week_start` 调生成。客户端拿到什么就用什么，绝不解释、绝不推算。

## 6. 构建环境与证书

两个 flavor（`local`、`server`），同一份源码，差的只有两样东西：

| | `local` | `server` |
| --- | --- | --- |
| 默认地址 | 模拟器访问宿主机的固定别名地址（`10.0.2.2` 那个），配 Windows 上跑的 `memora.exe` | 空串，必须在连接页手填——公网地址因此既不进仓库也不进 APK |
| 打进包的证书 | 只覆盖模拟器别名与回环地址那张，**进仓库**：值本身不含任何机器标识，换来"clone 完就能编译"，对应私钥不在仓库里 | 服务器上那张（SAN 是实际地址），只被拷进 `res/raw/`，永不进仓库 |
| 产物 | `app-local-debug.apk`，只进模拟器 | 装手机 |

模拟器不必非得连本机服务端：它和真机一样能出网，`serverDebug` 填云机地址就是同一条链路，差别只在打进包的那张证书（构建步骤见仓库 `android/README.md`）。

锁定方式是**把服务端那张证书作为唯一信任锚**（`network_security_config.xml` 里 `trust-anchors` 只引用 `@raw/memora_server_cert`，不设 `debug-overrides`，代码里也没有忽略证书的开关）。选它而不是 SPKI 摘要锁定，理由很实际：漏拷证书文件时资源不存在 → **编译失败**；而摘要写法漏了照样能编译，只会在运行时永远握手失败，报错还不说人话。把错误从运行期推到编译期，是这套 flavor 设计里最值钱的一条。

配套要求：签证书时用 `MEMORA_PUBLIC_IP=<地址1,地址2>` 传多个地址（`deploy/mkcert.sh` 支持逗号分隔，不带前缀按 IP 处理）。证书换了一定要重装 APK——这是 ADR-0009 明写的付出，客户端侧不做任何绕过。

## 边界与异常

- **正文为空或全空白**：不发请求，保存按钮置灰（服务端回 400，但没必要跑一趟）。
- **长度上限**：客户端按 2000 先挡并计数，**数的是码点数**——服务端那份是 `utf8.RuneCountInString`，按 UTF-16 长度算的话带表情符号的记录会被客户端提前挡下。真超限服务端回 413 不静默截断。两处都有这个数字是有意的取舍，见未决问题。
- **进程被杀**：输入变化后去抖 400ms 写草稿，重进编辑页先回填草稿；回填没完成前输入框不留给用户打字，否则那几个字会被后到的草稿盖掉。
- **删除**：连点两次才发请求（这个按钮和"取消"挨着，误触代价是丢一条只有手机上记得的想法）；成功回 204；已删除再删回 404，界面按"已经不在了"处理，不报错。
- **时间显示**：服务端给的是 UTC 时间戳，界面按手机时区格式化。**周期一律用服务端返回的 `week_start`/`month_start`**，不用手机日历推。
- **并发**：同一时刻只允许一个生成请求在飞（按钮禁用），服务端另有周期级互斥。
- **列表分页**：`limit=200`（服务端上限）加 `before` 游标翻页，不做本地缓存；上一页没满 200 条就收起"更早的"，到底了还亮着按钮，用户会当成网络问题。
- **刷新**：记录页和报表页各一个"刷新"按钮，加上从编辑页返回时自动重拉。没有下拉刷新（material3 里还是实验 API），也没有推送——另一台设备刚记的那条，这台上就是要点一下才看得见。

## 验收

分两级，各自验到什么要写清，别混着报：

1. **模拟器级**（`local` flavor + Windows 上 `memora.exe`）：记录增删改查、搜索、超限行文、口令错误与限速、报表生成与复制、failed 显示原因。这一级出不了门——它不碰公网，也证明不了手机能连上服务器。
2. **手机级**（`server flavor` + 服务器）：FR-01"两台设备看到同一条"、蜂窝网可达（要安全组入站规则已加）、真 DeepSeek 返回的报表质量。

工程第一次能算过：`./gradlew :app:assembleLocalDebug` 出 APK 且模拟器能读到 `memora.exe` 里的记录。版本不匹配导致同步失败属于预期内（本机没有 JDK 和 Android SDK，这些 Kotlin 文件在我这边一行都没编译过），按 Android Studio 提示升 AGP/Kotlin 即可，不用改业务代码。

## 未决问题

| 问题 | 卡住哪部分 | 计划怎么定 |
| --- | --- | --- |
| 上限 2000 在客户端是常量 | 只影响输入框计数与提示时机 | 先用常量 + 服务端 413 兜底；真要变成可配再开一个只读配置接口，不在 `periods/now` 里塞 |
| APK 签名密钥放哪 | `server` flavor 出 release 包 | 不进仓库；需求方本机生成，密码存他自己的密码管理器 |
| 改口令后的客户端体验 | 改了服务端哈希，旧口令立刻 401 | ADR-0009 已定行为，界面靠 401 跳连接页重输，不做额外入口 |
| 图标与应用名 | 纯外观 | 需求方定，当前用默认 |
| 生物识别解锁 | 现在只有 Keystore 加密的口令 | 需要时按 ADR-0010 的复查条件重谈 |
